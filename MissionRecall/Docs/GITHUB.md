# GitHub distribution

Repository: https://github.com/Mking99213/test-my-IQ

The current project lives in MissionRecall/. Download downloads/MissionRecall-UE5.8-Starter.zip from main. It contains source and setup assets, not a standalone executable.

Build MissionRecallEditor with your UE 5.8 toolchain, open MissionRecall.uproject, run Scripts/create_map.py in the editor, restart the editor and open LaunchSite. See SETUP.md, VSCODE.md and UPGRADE_5_8.md.

Full engine compilation and gameplay require local verification. To distribute a playable game, package through Unreal and upload the entire tested packaged output as a Release asset.
