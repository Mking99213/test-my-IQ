Repository: https://github.com/Mking99213/test-my-IQ

The starter is provided on the orbit-recall-starter branch under OrbitRecall/. Download downloads/OrbitRecall-UE5-Starter.zip for just the starter, or use GitHub Code → Download ZIP on that branch for all repository files.

Extract the archive completely, build the Editor target, run Scripts/create_map.py, restart Unreal, and open LaunchSite before pressing Play. See SETUP.md and VSCODE.md.

The provided archive contains source code, not a standalone executable. Package and test through Unreal before distributing a playable build. Portable C++ mission tests pass; full Unreal compilation and gameplay validation remain pending local verification.
